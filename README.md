# موقع الرسالة الرومانسية السرية الفاخرة | Personalized Romantic Secret Letter

موقع رومانسي تفاعلي متكامل ومبهر، مصمم بأعلى معايير الإتقان البصري وتجربة المستخدم (UI/UX) المستوحاة من الطابع الفيكتوري الكلاسيكي الفاخر. يتيح لك إنشاء رسالة حب سرية ومخصصة لشخصك المفضل، وحمايتها بكلمة سر، وإضافة معرض ذكريات عائم، وموسيقى رومانسية، وتوليد رابط خاص للمشاركة.

---

## ✨ المميزات الرئيسية

### 1. الهوية البصرية الكلاسيكية الفاخرة
- **خلفية مخملية بلون العنابي الداكن (Deep Burgundy #3B080F)** مع تدرجات ملكية وظلال واقعية وإضاءة محيطية دافئة.
- **مظروف واقعي فاخر (#590D19)** مع خطوط ثنيات دقيقة وعمق ثلاثي الأبعاد وظلال ناعمة تحاكي المظاريف الملكية القديمة.
- **ختم شمعي ذهبي (#D5B47A)** يحمل رمز القلب المنحوت مع لمعان وتوهج واقعي يتكسر ويزول بنعومة عند فتح المظروف.
- **ورقة رسالة كلاسيكية عاجية (#F2E3C3)** محاطة بإطارات دانتيل فيكتورية مطرزة وزخارف ذهبية في الأركان الأربعة.
- **خطوط عربية أصيلة وساحرة:** Amiri، Noto Naskh Arabic، Aref Ruqaa، وReem Kufi مع دعم كامل لاتجاه RTL.
- **جزيئات وقلوب ذهبية عائمة** تتطاير بخفة في الخلفية لتضفي سحراً شاعرياً على التجربة.

### 2. شاشة الفتح – المظروف والكلمة السرية
- في المنتصف: كلمة **"لَـكِ"** بخط عربي ذهبي مشرق مع إضاءة ساحرة.
- مظروف مغلق بختم الشمع الذهبي.
- حقل إدخال أنيق وشفاف لكتابة **"كلمة سرية"** مع زر دائري ذهبي أنيق.
- حماية أمنية وتشفير كامل على الخادم: لن يتمكن المتلقي من رؤية أي كلمة من الرسالة أو الذكريات دون كلمة السر الصحيحة.
- عند إدخال كلمة سر خاطئة: اهتزاز لطيف للزر ورسالة خطأ رومانسية دافئة.
- عند إدخال كلمة السر الصحيحة:
  - انطلاق تأثير المفرقعات الذهبية والوردية (Romantic Confetti).
  - تكسر الختم الشمعي الذهبي بنعومة.
  - انفتاح غطاء المظروف للأعلى بتقنية 3D.
  - خروج ورقة الرسالة العاجية من داخل المظروف وانزلاقها إلى مقدمة الشاشة بسلاسة سينمائية.

### 3. تجربة قراءة الرسالة الرومانسية
- بطاقة ورقية كلاسيكية عاجية فاخرة.
- ترويسة مخصصة قابلة للتعديل (افتراضياً: **"شخصي المفضل"**).
- اسم المحبوب مبرز بشكل شاعري راقٍ (مثال: **"إلى حبيبتي الغالية"**).
- نص الرسالة المنسق والمعدل مع فواصل ذهبية وزخرفة قلب في النهاية.
- زر بارز في أسفل الرسالة: **"الذكريات ❤️"** ينبض بنعومة للانتقال لمعرض الصور.

### 4. معرض الذكريات الـ 9 (الذكريات العائمة)
- عرض 9 بطاقات بولارويد كلاسيكية مطبوعة مع شريط لاصق جمالي (Washi Tape).
- درجات ميلان وتدوير عشوائية طبيعية (-4 إلى +4 درجات) لتجسيد إحساس ألبوم الذكريات الحقيقي (Scrapbook).
- حركة ثلاثية الأبعاد فريدة وسحرية عند التنقل: ترتفع الصورة في الهواء وتدور بزاوية 3D وتطفو بعيداً لتأتي الصورة التالية من زاوية سينمائية مغايرة.
- دعم كامل لإيماءات السحب باللمس (Swipe)، وأسهم التنقل الدائرية، وشريط النقاط المصغر.
- زر تبديل لعرض الشبكة الكاملة لجميع الصور الـ 9 معاً.
- تعليقات شاعريّة مكتوبة بخط يدوي أسفل كل صورة.

### 5. الموسيقى الخلفية
- مشغل موسيقى عائم وأنيق مع مؤشر نبضات وموجات صوتية متحركة.
- إمكانية تشغيل وإيقاف الصوت وكتمه.
- دعم رفع ملفات MP3 وتخصيص الرابط الصوتي من لوحة التحكم.
- تشغيل تلقائي هادئ بعد فتح المظروف وتفاعل المتلقي دون إزعاج.

### 6. لوحة تحكم الإدارة (Admin Dashboard)
- تسجيل دخول آمن ومحمي: `admin@secretletter.com` / `love2026`.
- **محتوى الرسالة:** تعديل العنوان، اسم المستلم، نص الرسالة، الخاتمة، وتغيير كلمة السر مع معاينة حية لشكل الورقة.
- **إدارة الذكريات (9 صور):** رفع الصور مباشرة إلى الخادم، تعديل الروابط، إعادة الترتيب للأعلى والأسفل، كتابة التعليقات، والحذف.
- **الموسيقى:** تفعيل أو تعطيل الموسيقى، ورفع ملفات MP3 واختبار المقطع قبل الحفظ.
- **تخصيص المظهر:** اختيار ألوان الخلفية والمظروف والورق والخط العربي وحجمه وتوسيطه، مع خيار تفعيل أو إلغاء الدانتيل والجزيئات.
- **النشر والمشاركة:** زر **"إنشاء رابط الرسالة ❤️"** الذي يقوم بحفظ التعديلات وتوليد رابط فريد وخاص لمشاركته بنقرة واحدة، مع خيار المعاينة المباشرة لتجربة المستلم.

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend):** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons, Canvas Confetti.
- **الخادم وقاعدة البيانات (Backend & DB):** Node.js, Express, Multer للرفع، Bcryptjs لتشفير كلمات السر، JWT للجلسات، ونظام تخزين دائم JSON Database.
- **التوافق السحابي مع Supabase:** ملف `supabase/schema.sql` جاهز تماماً ويتضمن تعريف الجداول (`letters`, `memories`) وسياسات الحماية الصارمة (Row Level Security - RLS) ودوال التحقق من كلمات السر.

## 🚀 تشغيل المشروع محلياً

1. الانتقال إلى مجلد المشروع:
```bash
cd "C:\Users\yossef\.gemini\antigravity\scratch\romantic-secret-letter"
```

2. تشغيل الخادم والواجهة:
```bash
npm run start
# أو لتشغيل الخادم المتكامل المستقل:
npx tsx server/index.ts
```

3. افتح الرابط في المتصفح:
- الموقع وتجربة المظروف: **http://localhost:3001**
- كلمة السر الافتراضية لفتح المظروف: **`123`**
- لوحة تحكم الإدارة: **http://localhost:3001/?admin=true**
- بيانات دخول المدير:
  - البريد: `admin@secretletter.com`
  - كلمة المرور: `love2026`
